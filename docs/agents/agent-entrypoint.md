# Agent entrypoint

Use this page to reach the smallest relevant source surface. Global rules remain authoritative in the repository [AGENTS.md](../../AGENTS.md).

## Discovery order

1. Read `AGENTS.md`.
2. Inspect the target route and its direct imports.
3. Read the matching shared content or component only when the route delegates to it.
4. Inspect the static GitHub Pages pipeline when the change affects routes, metadata, language alternates, redirects, sitemap data, or public output.
5. Select verification from `AGENTS.md` in proportion to the change.

The legacy `/facturation-electronique/` and `/expertises/` paths are redirects generated by `scripts/prepare-github-pages.mjs`; their vinext route files redirect or re-export the current public pages.

## Stable architecture anchors

- `components/PageLoader.tsx` handles navigation loading feedback.
- `components/SiteShell.tsx` handles shared navigation, stored language choice, in-page scrolling, and reveal observation.
- `github-pages/prerender.tsx` maps static routes to rendered React pages.
- `tests/rendered-html.test.mjs` covers rendered HTML, metadata, navigation, form behavior, and selected CSS contracts.

Do not create additional agent documents unless a recurring discovery problem cannot be solved by this router or a direct source link.
